ABOUT THIS CABINET

An original NetNet game starring aidunlap. Everyone gets the same level this week (UTC Sunday–Sunday seed). Inputs are recorded tick-by-tick; the score server re-simulates from scratch. The 3D view is a renderer on top of that deterministic sim. Runs that go faster than real time, pause, hide the tab or exceed the input-rate cap are rejected. Test credits only, not money. Three.js (MIT) vendored locally; all scene art is procedural / original.
