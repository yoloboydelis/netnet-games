ABOUT THIS CABINET

An original NetNet game starring aidunlap, the NetNet mascot. Genre inspiration only from browser snowball rollers — no third-party code, art or characters. Everyone gets the same level this week (seed from the UTC week, Sunday to Sunday). Every steer is recorded by tick and the score server re-plays the run from scratch; only the re-simulated score counts. Runs that go faster than real time, pause, hide the tab or exceed the input-rate cap are rejected. Tokens in the game are game items, not real assets or prices. Test credits only, not money.
