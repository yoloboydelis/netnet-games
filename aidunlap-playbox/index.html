ABOUT THIS CABINET

An original NetNet game starring aidunlap, the NetNet mascot. Everyone gets the same playbox this week (seed from the UTC week, Sunday to Sunday). Lever releases and mid-flight nudges are recorded by tick; the score server re-plays the run from scratch. Runs that go faster than real time, pause, hide the tab or exceed the input-rate cap are rejected. Test credits only, not money.

Inputs: 1–10 = spring power on release · 20 = nudge left · 21 = nudge right (max 2 per ball).
